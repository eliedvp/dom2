# Changeur de couleur — manipulation du DOM

Exercice réalisé pendant la formation GoMyCode : modifier dynamiquement le style d'un élément de la page en JavaScript.

## Ce que fait le projet

- Affiche un carré coloré et un bouton « Changer de couleur ».
- À chaque clic, une couleur hexadécimale aléatoire (`#RRGGBB`) est générée et appliquée au carré, avec une transition CSS.

## Notions travaillées

- Événement `DOMContentLoaded`
- Sélection d'éléments avec `getElementById`
- Écouteur d'événement sur un bouton
- Génération aléatoire avec `Math.random()` et `Math.floor()`
- Modification du style en JavaScript (`element.style.backgroundColor`)
- Transitions CSS

## Stack

HTML5, CSS3, JavaScript (sans bibliothèque).

## Lancer le projet

Ouvrir le fichier `index.html` dans un navigateur (aucune installation nécessaire).
